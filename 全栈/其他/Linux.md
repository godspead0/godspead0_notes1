## 二、Linux 权限管理

### 1. 权限的基本概念

- **角色分类**：每个文件/目录的权限归属 3 类角色：
    - 拥有者（u：user）：文件的创建者
    - 所属组（g：group）：文件所属的用户组（便于组内协作）
    - 其他用户（o：other）：非拥有者且不在所属组的用户
- **权限类型**：每个角色拥有 3 种基础权限：
    - r（read，读权限）：查看文件内容/目录下的文件列表
    - w（write，写权限）：修改文件内容/在目录下创建/删除文件
    - x（execute，执行权限）：运行可执行文件/进入目录
- **特殊说明**：
    - 目录的 `r` 权限：仅能查看目录下的文件列表，无法进入目录或查看文件内容
    - 目录的 `x` 权限：能否进入目录（`cd`）的关键，无 `x` 则无法访问目录内任何内容
    - 目录的 `w` 权限：能否在目录内创建、删除、重命名文件（与文件本身权限无关）

### 2. 权限的表示方式

#### （1）字符表示法（如 `-rw-r--r--`）

- 共 10 个字符，拆解如下：

    - | 第 1 位  | 第 2-4 位  | 第 5-7 位  | 第 8-10 位   |
        | -------- | ---------- | ---------- | ------------ |
        | 文件类型 | 拥有者权限 | 所属组权限 | 其他用户权限 |

- **文件类型（第 1 位）**：

    - `-`：普通文件（文本、源码、可执行文件等）
    - `d`：目录
    - `l`：符号链接文件（快捷方式）
    - `p`：管道文件（进程间通信）
    - `c`：字符设备文件（如键盘、鼠标）
    - `b`：块设备文件（如硬盘、U盘）

- 示例：`-rw-r--r-- 1 root root 0 2025-11-21 test.txt`

    - 文件类型：`-`（普通文件）
    - 拥有者权限：`rw-`（可读可写，无执行权限）
    - 所属组权限：`r--`（仅可读）
    - 其他用户权限：`r--`（仅可读）
    - 拥有者：`root`，所属组：`root`

#### （2）数字表示法（八进制，0-7）

- 每个权限对应一个比特位，r=4、w=2、x=1，权限组合为对应数值之和：
    - `rwx` = 4+2+1 = 7（可读可写可执行）
    - `rw-` = 4+2 = 6（可读可写）
    - `r--` = 4（仅可读）
    - `---` = 0（无任何权限）
- 数字权限格式：`所有者权限+所属组权限+其他用户权限`（如 755、644）
    - 755：`rwxr-xr-x`（目录默认权限，所有者可读写执行，其他仅读执行）
    - 644：`rw-r--r--`（文件默认权限，所有者可读写，其他仅读）

### 3. 权限修改命令

#### （1）修改权限：`chmod`

- **字符模式**：`chmod [u/g/o/a] [+/-/=] [r/w/x] 文件名`
    - `a`：all（所有角色）
    - `+`：添加权限、`-`：移除权限、`=`：设置权限（覆盖原有）
    - 示例：
        - `chmod u+x test.sh`：给拥有者添加执行权限
        - `chmod g-w test.txt`：给所属组移除写权限
        - `chmod o=rwx testdir`：给其他用户设置读、写、执行权限
        - `chmod a+r test.txt`：给所有角色添加读权限
- **数字模式**：`chmod 数字权限 文件名`
    - 示例：
        - `chmod 755 test.sh`：设置为 `rwxr-xr-x`（可执行文件常用）
        - `chmod 644 test.txt`：设置为 `rw-r--r--`（普通文件常用）
        - `chmod 000 test.txt`：移除所有角色的所有权限

#### （2）修改拥有者：`chown`

- 语法：`chown [拥有者][:所属组] 文件名`（需 root 权限或文件拥有者）
    - 示例：
        - `chown whb test.txt`：将文件拥有者改为 whb
        - `chown whb:whb test.txt`：同时将拥有者和所属组改为 whb
        - `chown -R whb:whb testdir`：递归修改目录及内部所有文件的拥有者和所属组

#### （3）修改所属组：`chgrp`

- 语法：`chgrp 所属组 文件名`
    - 示例：`chgrp dev test.txt`：将文件所属组改为 dev

### 4. 权限掩码：`umask`

- **作用**：控制新建文件/目录的默认权限（默认权限 = 起始权限 & (~umask)）
- **起始权限**：
    - 目录起始权限：777（`rwxrwxrwx`）
    - 普通文件起始权限：666（`rw-rw-rw-`，默认无执行权限，避免误执行）
- **默认 umask**：0022（不同系统可能不同）
    - 新建目录默认权限：777 & (~0022) = 755（`rwxr-xr-x`）
    - 新建文件默认权限：666 & (~0022) = 644（`rw-r--r--`）
- **修改 umask**：
    - 临时修改：`umask 0002`（仅当前终端生效）
    - 永久修改：写入 `/etc/profile`（全局）或 `~/.bashrc`（当前用户）

### 5. 粘滞位（Sticky Bit）

- **作用**：给目录添加粘滞位后，仅 root、目录拥有者、文件拥有者可删除该目录下的文件（防止其他用户恶意删除组内共享文件）
- **设置方法**：`chmod +t 目录名`（权限字符最后一位变为 `t`）
    - 示例：`chmod +t /tmp/shared`（共享目录常用配置）
- **权限表示**：添加粘滞位后，其他用户权限的 `x` 变为 `t`（如 `rwxrwxrwt`）

| 命令模式（Normal）       | 打开 Vim 默认进入                                            | 移动光标、复制、删除、撤销等 | 按 `i`/`a`/`o` 进入插入模式；按 `:` 进入底行模式 |
| 插入模式（Insert）       | 命令模式下按 `i`（光标前插入）、`a`（光标后插入）、`o`（换行插入） | 编辑文件内容（类似记事本）   | 按 `Esc` 回到命令模式                            |
| 底行模式（Command-line） | 命令模式下按 `:`                                             | 保存、退出、查找、替换等     | 执行命令后自动回到命令模式；按 `Esc` 取消命令    |
| 替换模式（Replace）      | 命令模式下按 `R`                                             | 覆盖光标位置的字符           | 按 `Esc` 回到命令模式                            |
| 视图模式（Visual）       | 命令模式下按 `v`（字符选择）、`V`（行选择）                  | 批量选择文本（复制、删除）   | 按 `Esc` 回到命令模式                            |

### 2. 常用操作（重点）

#### （1）文件操作（底行模式）

- `:w`：保存文件（不退出）
- `:w 文件名`：另存为指定文件
- `:q`：退出 Vim（文件未修改时）
- `:q!`：强制退出（放弃修改）
- `:wq` 或 `:x`：保存并退出
- `:e 文件名`：在当前 Vim 中打开另一个文件

#### （2）光标移动（命令模式）

- 上下左右：`k`（上）、`j`（下）、`h`（左）、`l`（右）（无需方向键）
- 行内：`^`（移到行首）、`$`（移到行尾）、`w`（移到下一个单词开头）
- 行间：`gg`（移到文件首行）、`G`（移到文件尾行）、`nG`（移到第 n 行，如 `5G` 移到第 5 行）
- 翻页：`Ctrl+f`（向下翻页）、`Ctrl+b`（向上翻页）

#### （3）文本编辑（命令模式）

- 复制：`yy`（复制当前行）、`nyy`（复制 n 行，如 `3yy` 复制 3 行）、`y`（视图模式下复制选择的文本）
- 粘贴：`p`（粘贴到光标后）、`P`（粘贴到光标前）
- 删除：`dd`（删除当前行）、`ndd`（删除 n 行）、`x`（删除光标位置的字符）、`d`（视图模式下删除选择的文本）
- 撤销/重做：`u`（撤销上一步操作）、`Ctrl+r`（重做撤销的操作）
- 查找：命令模式下按 `/关键词`（向下查找）、`?关键词`（向上查找），按 `n` 下一个匹配、`N` 上一个匹配

## 四、Makefile 自动化构建工具

### 1. 核心原理

- Makefile 是一个文本文件，定义了“目标文件”、“依赖文件”和“构建命令”，`make` 命令会根据文件的修改时间（Modify Time）判断是否需要重新构建（仅当依赖文件比目标文件新时才执行构建）。
- 语法规则：
    - ```Makefile
        目标文件: 依赖文件列表
            构建命令（必须以 Tab 开头，不能用空格）
        ```

### 2. 基础语法示例

假设项目有 `main.c`、`func.c` 两个源文件，生成可执行文件 `app`：

```Makefile
# 注释：# 开头为注释
app: main.c func.c  # 目标：app；依赖：两个源文件
    gcc main.c func.c -o app  # 构建命令（Tab 开头）

# 清理目标（伪目标）
.PHONY: clean  # .PHONY 声明伪目标（不生成文件，强制执行命令）
clean:
    rm -rf app  # 删除可执行文件
```

- 执行 `make`：默认构建第一个目标（app）
- 执行 `make clean`：执行 clean 目标，删除 app

### 3. 高级用法（变量与通配符）

#### （1）自动变量（简化语法）

- `$@`：当前目标文件名（如 app）
- `$^`：当前目标的所有依赖文件（如 main.c func.c）
- `$<`：当前目标的第一个依赖文件

```Makefile
app: main.c func.c
    gcc $^ -o $@  # 等价于 gcc main.c func.c -o app
```

#### （2）通配符与变量

- `*.c`：匹配所有 `.c` 源文件
- 自定义变量：简化重复内容（如编译器、编译选项）

```Makefile
CC = gcc  # 编译器变量
CFLAGS = -Wall -g  # 编译选项（-Wall 显示警告，-g 生成调试信息）
SRC = $(wildcard *.c)  # 匹配所有 .c 文件，存入 SRC 变量
OBJ = $(SRC:.c=.o)  # 将 SRC 中的 .c 替换为 .o，生成目标文件列表
TARGET = app  # 最终可执行文件名

$(TARGET): $(OBJ)
    $(CC) $(CFLAGS) $^ -o $@

# 生成 .o 目标文件（隐含规则，可省略，但显式写更清晰）
%.o: %.c
    $(CC) $(CFLAGS) -c $< -o $@

.PHONY: clean
clean:
    rm -rf $(TARGET) $(OBJ)
```

### 4. 关键说明

- **伪目标（.PHONY）**：
    - 用于声明“不生成文件的目标”（如 clean），避免目录中存在与目标名相同的文件时，`make` 误判为“目标已存在”而不执行命令。
    - 不可用于可执行文件目标（如 app），否则会忽略文件修改时间，每次执行 `make` 都会重新编译。
- **依赖关系**：依赖文件列表可以为空（如 clean 目标），此时仅执行构建命令。
- **执行顺序**：`make` 会从第一个目标开始执行，若依赖文件不存在，会先查找是否有对应的目标规则来生成该依赖文件（递归推导）。

## 五、重要概念补充

### 1. 管道符（|）

- 作用：将前一个命令的输出作为后一个命令的输入，实现命令联动。
- 示例：
    - `ls -l | grep ".txt"`：列出当前目录下所有 `.txt` 文件的详细信息
    - `ps -ef | grep ssh | grep -v grep`：查找 ssh 进程（排除 grep 自身）
    - `cat test.txt | sort | uniq`：对文件内容排序并去重

### 2. 缓冲区

- 缓冲区是内存中的临时存储区域，用于加速数据 I/O（减少磁盘读写次数）。
- 常见场景：C 语言中 `printf` 输出默认会缓冲，需满足“换行符 `\n`”“缓冲区满”或“程序结束”才会刷新到终端。
- 手动刷新缓冲区：`fflush(stdout)`（C 语言），或使用 `setbuf(stdout, NULL)` 关闭缓冲。

### 3. 环境变量

- 环境变量是系统级的变量，用于存储系统配置信息（如 `PATH`、`HOME`）。
- 常用环境变量：
    - `PATH`：系统查找可执行文件的目录列表（添加自定义程序路径需修改 `PATH`）
    - `HOME`：当前用户的家目录路径
    - `USER`：当前登录用户名
- 操作：
    - 查看环境变量：`echo $变量名`（如 `echo $PATH`）
    - 临时修改：`export PATH=$PATH:/自定义路径`（当前终端生效）
    - 永久修改：写入 `~/.bashrc`（用户级）或 `/etc/profile`（系统级），执行 `source 文件名` 立即生效
