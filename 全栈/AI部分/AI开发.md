# 一、你必须掌握的 AI 核心能力（全栈通用）

## 1. LLM 基础（1 天搞定）

- 理解：**Prompt、System Prompt、Token、上下文窗口**
- 会调参数：**temperature、top_p、max_tokens**
- 知道什么是**幻觉、 hallucination**

## 2. 文本转向量（Embedding）（半天）

- 什么是**向量、Embedding**
- 会调用 API 生成向量
- 知道**语义相似度**是干嘛的

## 3. RAG（检索增强生成）（3 天）

- 这是**现在 90% AI 项目的核心**

- 流程：

    

    文档 → 分块 → 转向量 → 存向量库 → 检索 → 塞给 LLM 回答

- 必须会：**长文档问答、知识库、企业内部问答**

## 4. Function Calling / 工具调用（2 天）

- 让 AI **调用你写的接口**
- 查数据库、调接口、查天气、查订单、跑代码
- 做**AI 助手、智能客服、自动化工具**必备

## 5. AI Agent（智能体）（1 周）

- 让 AI 自己**思考 → 规划 → 查资料 → 调用工具 → 得出结果**
- 未来 3 年主流方向

## 6. 流式输出（Stream）（半天）

- 实现像 ChatGPT 那样**一字一字蹦出来**
- 前端体验必备

2. **Embedding API**

3. 向量库

    - Chroma、Milvus、FAISS

    

4. RAG 框架

    - LangChain / LlamaIndex（会一个就行）

    

5. 后端

    - Python：FastAPI / Flask

## 进阶（涨薪、做高级项目）
