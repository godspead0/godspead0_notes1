# 关键字



| 分类                     | 关键字                  | 用法说明                                                     | 示例                                                         |
| ------------------------ | ----------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **数据类型关键字**       | `boolean`               | 定义布尔类型变量，只有 `true` 和 `false` 两个值，常用于逻辑判断 | `boolean isDone = true;`                                     |
| **数据类型关键字**       | `byte`                  | 定义字节型变量，取值范围为 -128 到 127，适用于节省内存空间的场景 | `byte num = 10;`                                             |
| **数据类型关键字**       | `char`                  | 定义字符型变量，用于存储单个字符，需用单引号括起来           | `char letter = 'A';`                                         |
| **数据类型关键字**       | `double`                | 定义双精度浮点型变量，是默认的小数类型，精度较高             | `double pi = 3.1415926;`                                     |
| **数据类型关键字**       | `float`                 | 定义单精度浮点型变量，常量需加 `f` 或 `F` 后缀，占用内存空间较 `double` 小 | `float e = 2.718f;`                                          |
| **数据类型关键字**       | `int`                   | 定义整型变量，是最常用的整数类型，可表示较大范围的整数       | `int count = 5;`                                             |
| **数据类型关键字**       | `long`                  | 定义长整型变量，用于表示更大范围的整数，常量需加 `L` 或 `l` 后缀 | `long bigNumber = 1234567890123L;`                           |
| **数据类型关键字**       | `short`                 | 定义短整型变量，取值范围为 -32768 到 32767                   | `short number = 100;`                                        |
| **数据类型关键字**       | `void`                  | 用于定义无返回值的方法，或表示方法返回值类型为空             | `public void printMessage() { System.out.println("Hello"); }` |
| **流程控制关键字**       | `break`                 | 用于跳出当前循环（`for`、`while`、`do - while`）或 `switch` 语句 | `for (int i = 0; i < 5; i++) {if (i == 3) {break;}System.out.println(i);}` |
| **流程控制关键字**       | `case`                  | 配合 `switch` 语句使用，用于匹配 `switch` 表达式的值         | `int day = 3;switch (day) {case 1:System.out.println("Monday");break;case 2:System.out.println("Tuesday");break;case 3:System.out.println("Wednesday");break;}` |
| **流程控制关键字**       | `continue`              | 用于跳过当前循环体中剩余语句，直接开始下一次循环             | `for (int i = 0; i < 5; i++) {if (i == 2) {continue;}System.out.println(i);}` |
| **流程控制关键字**       | `do - while`            | 循环语句，先执行一次循环体，再判断条件，至少执行一次循环体   | `int count = 0;do {System.out.println(count);count++;} while (count < 3);` |
| **流程控制关键字**       | `else`                  | 与 `if` 语句配合使用，当 `if` 条件为 `false` 时执行 `else` 块中的代码 | `int score = 55;if (score >= 60) {System.out.println("Pass");} else {System.out.println("Fail");}` |
| **流程控制关键字**       | `for`                   | 循环语句，常用于已知循环次数的场景，有初始化、条件判断和迭代部分 | `for (int i = 0; i < 5; i++) {System.out.println(i);}`       |
| **流程控制关键字**       | `if`                    | 条件判断语句，当条件为 `true` 时执行 `if` 块中的代码         | `int num = 10;if (num > 5) {System.out.println("Greater than 5");}` |
| **流程控制关键字**       | `return`                | 用于从方法中返回值并结束方法，如果方法返回类型为 `void`，则 `return` 可省略返回值 | `public int add(int a, int b) {return a + b;}`               |
| **流程控制关键字**       | `switch`                | 多分支选择语句，根据表达式的值与各个 `case` 常量表达式的值进行匹配 | `int day = 3;switch (day) {case 1:System.out.println("Monday");break;case 2:System.out.println("Tuesday");break;case 3:System.out.println("Wednesday");break;}` |
| **流程控制关键字**       | `while`                 | 循环语句，先判断条件，条件为 `true` 时执行循环体             | `int num = 0;while (num < 3) {System.out.println(num);num++;}` |
| **类、对象和继承关键字** | `abstract`              | 用于定义抽象类或抽象方法。抽象类不能被实例化，抽象方法必须在子类中被重写 | `abstract class Shape {public abstract void draw();}class Circle extends Shape {@Overridepublic void draw() {System.out.println("Drawing a circle");}}` |
| **类、对象和继承关键字** | `class`                 | 用于定义类，类是封装数据和行为的基本单元                     | `class Person {String name;int age;public void sayHello() {System.out.println("Hello, my name is " + name);}}` |
| **类、对象和继承关键字** | `enum`                  | 用于定义枚举类型，是一种特殊的数据类型，它限制变量只能取特定的值集合 | `enum Day {MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY}Day today = Day.MONDAY;` |
| **类、对象和继承关键字** | `extends`               | 用于类的继承，子类通过 `extends` 继承父类的属性和方法        | `class Student extends Person { String school; }`            |
| **类、对象和继承关键字** | `final`                 | 用于修饰类、方法和变量。修饰类时，该类不能被继承；修饰方法时，该方法不能被重写；修饰变量时，该变量成为常量 | `final class FinalClass {}class FinalMethodExample {public final void finalMethod() {}}class FinalVariableExample {final int num = 10;}` |
| **类、对象和继承关键字** | `implements`            | 用于类实现接口，类需实现接口中定义的抽象方法                 | `interface Runner {void run();}class Athlete implements Runner {@Overridepublic void run() {System.out.println("The athlete is running");}}` |

| **访问控制关键字**       | `private`               | 修饰的成员（方法、属性）只能在本类内部被访问                 | `class PrivateClass { private int privateVar; private void privateMethod() {} }` |
| **访问控制关键字**       | `protected`             | 修饰的成员可被本类、子类以及同一个包中的其他类访问           | `class ProtectedClass { protected int protectedVar; protected void protectedMethod() {} }` |

# 书写顺序

在 Java 中，关键字并没有严格固定的 “书写顺序” 要求，它们的使用取决于具体的编程逻辑和语法结构。不过，在不同的语法场景下，关键字会遵循相应的语法规则出现。以下按照常见的 Java 编程结构，为你梳理关键字的一般使用顺序：

### 1. 类定义

```java
[访问修饰符] [修饰符] class 类名 [extends 父类] [implements 接口列表] {
    // 类成员（变量、方法等）定义
}
```

- **访问修饰符**：如`public`、`private`、`protected`、`default`，用于控制类、成员变量和方法的访问权限，通常放在最前面。
- **修饰符**：例如`abstract`（抽象类）、`final`（最终类，不能被继承），紧跟访问修饰符之后，用于进一步定义类的特性。
- `class`：定义类的关键字，用于声明一个新的类。
- `extends`：用于继承父类，可选，跟在类名之后。
- `implements`：用于实现接口，可选，紧跟在`extends`（如果有）之后，列出要实现的接口列表。

### 2. 方法定义

```java
[访问修饰符] [修饰符] [返回类型] 方法名([参数列表]) [throws 异常列表] {
    // 方法体
}
```

- **访问修饰符**：同上述类定义中的访问修饰符，确定方法的访问范围。
- **修饰符**：如`abstract`（抽象方法）、`final`（最终方法，不能被重写）、`static`（静态方法，属于类而不是实例）、`synchronized`（多线程同步方法）等，紧跟访问修饰符。
- **返回类型**：可以是基本数据类型（如`int`、`boolean`等）、引用类型（如自定义类、接口）或`void`（无返回值）。
- **方法名**：遵循 Java 标识符命名规则，定义方法的名称。
- **参数列表**：定义方法接受的参数，多个参数以逗号分隔，每个参数由参数类型和参数名组成。
- `throws`：可选，用于声明该方法可能抛出的异常列表。

### 3. 变量声明

```java
[访问修饰符] [修饰符] 数据类型 变量名 [= 初始值];
```

- **访问修饰符**：如在类中定义成员变量时，用于控制变量的访问权限。
- **修饰符**：如`final`（常量）、`static`（静态变量）、`transient`（序列化时忽略该变量）、`volatile`（多线程环境下保证变量可见性）等。
- **数据类型**：可以是基本数据类型或引用类型。
- **变量名**：遵循 Java 标识符命名规则。
- **初始值**：可选，用于在声明变量时给变量赋初始值。

### 4. 流程控制语句

- **`if - else`语句**：

```java
if (条件表达式) {
    // 条件为true时执行的代码块
} else {
    // 条件为false时执行的代码块
}
```

`if`关键字后紧跟条件表达式，然后是条件为`true`时执行的代码块，`else`关键字（可选）后是条件为`false`时执行的代码块。

- **`switch - case`语句**：

```java
switch (表达式) {
    case 常量表达式1:
        // 执行代码块1
        break;
    case 常量表达式2:
        // 执行代码块2
        break;
    default:
        // 所有case都不匹配时执行的代码块
}
```

`switch`关键字后是要判断的表达式，`case`关键字后跟常量表达式和对应的执行代码块，`default`关键字（可选）用于处理所有`case`都不匹配的情况。

- 循环语句（`for`、`while`、`do - while`）：
  - **`for`循环**：

```java
for (初始化表达式; 条件表达式; 迭代表达式) {
    // 循环体
}
```

`for`关键字后依次是初始化表达式、条件表达式和迭代表达式，中间用分号分隔，然后是循环体。

- **`while`循环**：

```java
while (条件表达式) {
    // 循环体
}
```

`while`关键字后紧跟条件表达式，然后是循环体。

- **`do - while`循环**：

```java
do {
    // 循环体
} while (条件表达式);
```

先执行`do`后的循环体，再判断`while`后的条件表达式。

- **`try - catch - finally`语句**：

```java
try {
    // 可能抛出异常的代码块
} catch (异常类型1 异常变量1) {
    // 处理异常类型1的代码块
} catch (异常类型2 异常变量2) {
    // 处理异常类型2的代码块
} finally {
    // 无论是否发生异常都会执行的代码块
}
```

`try`关键字后是可能抛出异常的代码块，紧跟多个`catch`块用于捕获不同类型的异常并处理，`finally`关键字（可选）后的代码块无论是否发生异常都会执行。
